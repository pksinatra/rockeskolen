# Rockeskolen – instrukser for agenter

**Les `CLAUDE.md` i repo-roten før du gjør endringer.** Den er felles for Claude og Codex og inneholder alle tekniske, redaksjonelle og publiseringsmessige regler. Ved motstrid gjelder de nyeste, eksplisitte instruksene fra brukeren.

Arbeidsdeling: Claude tar det tekniske. Codex og ChatGPT står for planleggingen.

## Faste redaksjonelle regler (kortversjon)

- Rockeskolen bruker internasjonale tonenavn: **B**, aldri H som navn på tonen. Dette gjelder konsekvent i artikler, akkorder, skalaer, verktøy, diagrammer, menyer og undervisningstekst.
- Den senkede tonen skrives **B♭** (eller Bb i teknisk tekst), ikke B i den tyske/norske H-tradisjonen.
- Historiske forklaringer som sammenligner B og H kan omtale H som begrep, men Rockeskolens egne toneeksempler og brukergrensesnitt skal bruke B.
- Bevar eksisterende brukerarbeid. Produksjonsinnhold i Drupal må hentes før redigering; lokale kopier kan være eldre.

- Bruk **loop** som norsk musikkbegrep. Ikke oversett loop til «sløyfe» i musikkverktøy, artikler eller undervisningstekst.
- Akkorder og tonearter skrives med vanlige tegn (Bb, F#m, Eb-dur). Enkelttoner og noter skrives med ♭/♯ (E♭, F♯).
- Det finnes bare én forside: `index.php`. Ingen `index.html`.
- Ingen mapper flyttes, opprettes, omdøpes eller slettes uten brukerens godkjenning. All rydding krever dobbel bekreftelse.
- Ingen FTP-opplasting eller push uten godkjenning.
