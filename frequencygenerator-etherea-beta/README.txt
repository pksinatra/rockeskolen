FREQUENCY GENERATOR — WEB AUDIO PROTOTYPE

Files:
- index.html
- styles.css
- app.js

Run:
1. Put all three web files in the same folder.
2. Open index.html in a modern browser, or upload the folder to any ordinary web host.
3. Audio starts only after a user click/tap, as required by modern browsers.

Included:
- Single tone generator
- Exact Hz input
- Logarithmic/linear slider
- Frequency range selection
- Note + cents readout with 440/442/432 tuning reference
- Fine frequency nudge controls and octave halve/double
- Sine / triangle / square / sawtooth
- Master volume and stereo balance
- Waveform visualization
- Multi oscillator generator (up to 8 tones)
- Sweep generator with linear/log curve, up/down/ping-pong and loop
- Binaural generator with symmetrical / fixed-side calculation
- White / pink / brown noise
- Built-in presets and local custom presets
- Shareable URL state for main tone settings
- Click-safe short fade in/out

Important:
The 0–100% volume control is digital amplitude, not calibrated sound pressure level (dB SPL).
Actual audible frequency range and output level depend on the device, DAC, amplifier, speakers/headphones and browser/OS.
